## 6. How the App Works

**App Purpose:** This app is designed to REPLACE physical cards during gameplay to randomize cards and save table space. However, physical cards are ALWAYS the authoritative source of truth if there is any doubt or discrepancy.

The App is a self-contained tool that:

- **Randomizes and manages game cards digitally** - Replaces physical card decks to save table space
- Helps players select locations on the physical Arkham Horror board game
- **Stores game card information in a LOCAL DATABASE on your device only** - This database cannot be changed by users and does not require any user information
- **Does NOT offer any type of communication** - No chat, messaging, multiplayer, social features, or any form of user-to-user communication
- **Does NOT save any user information** - No personal data, accounts, profiles, or user-generated content is stored
- **Works completely OFFLINE** - The app can be used without WiFi, internet connection, or any type of network signal. No network connection is required or used.
- Does not communicate with external servers or services
- Does not send or receive any data over the internet
- **Language: English ONLY** - The app and all card content are in English only, regardless of the user's country or location
- **Does NOT use user location** - The app does not access, collect, or use GPS coordinates, location data, or country information
